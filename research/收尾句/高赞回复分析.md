## 2. 这些收尾句为什么被点赞

### 2.1 量化（上表 50 条完整原句）

- **长度**：中位数 15.5 字，平均 18 字。10 字以内 6 条，11–20 字 27 条，21–30 字 15 条，超过 30 字只有 2 条。
- **节奏**：平均每句 1 个逗号，最多 3 个，最常见的是**两拍**：前半句铺垫，后半句落点，落点在句尾（“其实这是孤独”“不过如此”“这个躯体属于自己”）。
- **人称**：没有人称的判断句 26 条，“你”17 条，“我”5 条，“我们”4 条。没有人称是因为它要让一大群路人都能认领；我们只对一个人说话，应该用“你”。
- **标点**：问号 2 条（其中 1 条是反问），感叹号 1 条。高赞收尾句基本是陈述句。
- **祈使句很少**：带“去做什么”的只有 #25、#34 两条，读起来更像语录，不像回复。

### 2.2 质性观察

1. **被认领**：读者觉得“这说的就是我”。靠的是读者自己会说的词（“没事”“算了”）、自己经历过的小画面（饺子、第二杯半价、车里、最后一条没回的消息），不靠形容词。
2. **说准一个名字，比十句安慰管用**：#6、#18、#21、#32 都是给一团说不清的难受起了个准名字，读的人会松一口气。
3. **诚实**：敢说时间治不好（#12）、房贷不允许（#35）、孤独是常态（#50），反而更可信。
4. **拿走负担**：豆瓣高赞楼层最常做的两件事，一是拿走羞耻（#45 不丢人），二是拿走责任（#46 不是你的问题），然后接住楼主提到的一个细节（#47 同事）。这是最接近我们产品的样本。
5. **停在落点上**：说完判断就停，不补一句“所以你要……”，也不祝福。

### 2.3 高赞句和我们的收尾句不是一回事

| | 高赞回复 | 我们的收尾句 |
|---|---|---|
| 写给谁 | 一大群路人 | 今天这一个人 |
| 想要什么 | 被转发、被截图 | 被这一个人认领，不需要被转发 |
| 素材 | 人人都有的经历 | 他今天亲口说过的一个细节 |
| 人称 | 多半没有人称 | “你” |
| 风险 | 金句化、网抑云式自怜 | 说空、说教、像客服结束语 |

结论：**借结构，不借普遍性。** 句式可以学高赞（命名、区分、许可、画面、两拍），内容必须来自今天的对话。一句换给别的用户也成立的收尾句，就是写空了。

## 3. 规律

每条后面的例句是原创，括号里是假设他今天说过的话。

**1. 重新命名** ｜半格为主
把他给这件事起的名字（“我太怂”“我矫情”）换成更准、也更不伤人的那个。读的人会有“被说中”的解脱。对应 #6 #18 #21 #32 #36。
例：（他说拖了一个月没交辞职信，骂自己怂）拖了一个月不是怂，是你还没算清走了以后房租从哪来。

**2. 拆成两件事** ｜半格
“A 是 A，B 是 B”，或“不是 A，是 B”。把粘在一起的两样东西分开，罪恶感往往就落在其中一半上，另一半可以放下。对应 #11 #16 #20 #28 #31。
例：（他说分手后还天天翻她朋友圈）想她是一回事，翻朋友圈是另一回事，后一件只是手比心先习惯了。

**3. 拿走不该他背的** ｜两者
羞耻、自责、“是不是我的问题”。直接说出这件事不是他的错，或者不丢人。豆瓣高赞楼层最常用。对应 #3 #45 #46。
例：（他说在工位上哭，被同事看见了）在工位上哭不丢人，那封邮件换谁收到都绷不住。

**4. 给许可** ｜平坐为主
允许他暂时不改变、不回复、不原谅、不想通。许可要具体到一件事，不能是“做你自己就好”。对应 #13 #43。
例：（他说妈妈催了一晚上要他回电话）你妈那个电话，今晚先不回也行。

**5. 用一个小画面代替抽象词** ｜两者，平坐更常用
用他提到的物件、时间、地点、动作，不用“压力”“孤独”“状态”。画面要从他的话里取，不能自己编。对应 #1 #2 #5 #14 #23 #28。
例：（他说下班地铁坐过了三站）坐过三站那会儿，大概是你今天唯一没在想工作的时候。

**6. 拆穿一句套话** ｜半格为主，平坐可轻用
先承认一句常听到的劝，再说它在他这儿不成立。敢否定鸡汤的话，听的人才会信。对应 #1 #12 #35。
例：（他说大家都劝他想开点）想开点这话没错，只是你缺的不是想开，是有人承认这事确实不公平。

**7. 说出他没说出口的那层（盖章）** ｜平坐为主，半格也用
他绕了一晚上没说的那句，多半是自责、委屈或者还在乎，替他说出来。说出来就是赦免，不是说服。对应 #4 #9 #15 #24 #42。
例：（他说爸爸住院，他在外地回不去，爸爸电话里还让他别回）他让你别回是心疼你，你回不去，心里比谁都急。

**8. 缩小尺度** ｜两者
把“完了”“毁了”放回实际的大小：一个下午、一次考试、别人三分钟的注意力。对应 #13 #40 #41 #50。
例：（他说年会上说错一句话，没脸见人）那句话同事记住的时间，大概没有你今晚想它的时间长。

**9. 对仗和回环** ｜半格可用，要慎用
前后两半结构一样，只换一两个字，读起来像盖棺。这是高赞里最常见的句式，也最容易滑成鸡汤。只能用他自己的词来搭。对应 #8 #20 #22 #27 #36 #44。
例：（他说以前怕她不回消息，现在怕她回）以前怕她不回，现在怕她回，变的是你，对话框还是那个对话框。

**10. 停在一个动作上，不解释** ｜平坐
不下结论，句子停在一件具体的事上，后面让他自己接。对应 #2 #16 #23。
例：（他说和老朋友的聊天记录停在去年春节）聊天记录停在去年春节，那就先让它停着。

**11. 一点自嘲或冷幽默** ｜两者，要慎用
只在他自己先开过玩笑、情绪已经松下来时用，接他的梗，不另造梗。对应 #14 #23 #39。
例：（他自嘲“我是公司的承重墙”，加班到十点）承重墙今晚也下班了，楼塌不了。

**12. 把选择放回他手里** ｜半格
不给答案，只说清这件事的决定权在他，而且他今天已经把要付的代价看清了。不能写成“你可以试试……”。对应 #37。
例：（他纠结要不要回老家，聊了两边的代价）回不回老家，两边要付什么你今天都摆出来了，挑哪边都算数。

## 4. 反例：像鸡汤或像 AI 的收尾

以下都是编的坏例子。

| 毛病 | 坏例子 | 为什么不行 |
|---|---|---|
| 排比 | 相信时间，相信自己，相信明天。 | 三连句是演讲腔，一眼就是模板 |
| 大道理、升华 | 人生就是一场修行，每一次失去都是成长。 | 把他的事拔高到人生，等于没听他说什么 |
| “愿你……” | 愿你被这个世界温柔以待。 | 祝福体，客服和公众号的结尾 |
| 加油打气 | 加油，你一定可以的！ | 不知道他能不能，也不是他要的 |
| 空头保证 | 一切都会好起来的。 | 没人能保证；高赞句恰恰是敢说“不会自动好”的那种 |
| 空泛形容词 | 你是一个善良、勇敢又温柔的人。 | 三个形容词放谁身上都成立 |
| 说教、布置任务 | 下次记得先照顾好自己，别总为别人活。 | 结束时还在教他做人 |
| 反问收尾 | 难道你不值得更好的吗？ | 逼他点头，像辩论，不像告别 |
| 流程式总结 | 今天我们聊了工作和父母，希望对你有帮助。 | 会议纪要加客服用语 |
| 万能金句 | 成年人的世界没有容易二字。 | 换给谁都成立，没人会认领 |
| 假区分 | 放下的不是他，是曾经的自己。 | 有“不是 A 是 B”的壳，内容和今天无关，是穿了半格外衣的鸡汤 |
| 贴标签、诊断 | 你这是典型的讨好型人格。 | 半格和平坐都不下诊断 |
| 承诺 | 我会一直在这里等你。 | 平坐不承诺“永远”，也像在拉留存 |
| 表情、感叹 | 抱抱你！🤗 | 违反去 AI 味规则 |
| 夸张 | 你今天的勇敢，足以照亮整个冬天。 | 煽情，比喻和他的事无关 |

## 5. 对产品的建议

**长度和形式**
- 一句话，15–40 个汉字，硬上限 45 字。语料中位数是 15.5 字；我们要放进一个具体细节，所以可以稍长一点。
- 最多两个逗号，以句号结尾。不用问号、感叹号、省略号、破折号、表情符号，不换行，不加引号包整句。

**必须有的**
- 落在他今天亲口说过的一个具体东西上：人、数字、时间、物件、动作，尽量用他的原词（他说“烦”，就写“烦”）。
- 他聊了好几件事时只挑一件：他反复回到的那件，或者说得最多、情绪最重的那件。不要一句话里串起所有话题。

**不能有的**
- 建议、任务、“下次可以……”；提问；祝福；“今天我们聊了……”；承诺；给他或不在场的人贴标签；“希望对你有帮助”；提评分（评分弹窗紧接着就出来，不要再提）。
- 去 AI 味禁词照旧：愿你、加油、会好的、都会过去、辛苦了、抱抱、你已经很棒了、你值得、其实、成长、内耗、情绪价值。

**半格和平坐怎么分**

| | 半格 | 平坐 |
|---|---|---|
| 落点 | 一句定性或区分（规律 1、2、6、8、9、12） | 一个画面加一句许可，或替他说出那层（规律 3、4、5、7、10） |
| 句式 | “不是……是……”“……是……，……是……” | 平常的话，像随口一句，不对仗，不造金句 |
| 温度 | 取材冷，落点暖：区分的结果要替他拿掉一点罪恶感 | 低、慢，不煽情 |
| 风险 | 区分没从他的话里长出来，就变成假区分 | 太短太空，变成“嗯，早点睡” |

**他今天几乎没说什么时**（比如只发了一两句，或者一直“嗯”）
- 不编细节，也不硬做区分。
- 就说“来过、坐过”这件事本身，或者落在他唯一说过的那个词上。
- 平坐：“今天话不多，来坐一会儿也算。”半格：“没说出口的那部分不急，它不会因为今天没说就不算数。”
- 可以准备几句兜底句，模型输出不合格时用。

**特殊情况**
- 对话里出现过自伤、轻生信号：安全优先，这句收尾可以破例写成两句，必须带上“在乎他现在安不安全”和 12356 热线，紧急时 110／120。
- 他最后和人格闹得不愉快（说“你说得不对”“别说了”）：收尾不续上争论，半格只把决定权还给他。
- 他最后情绪已经松下来，甚至在开玩笑：收尾别再把伤口揭开，接住他最后的轻松即可。

**工程上**
- 生成后用规则过滤：字数、问号、感叹号、表情、禁词列表、“今天我们聊了”。不合格就重生成一次，再不合格用兜底句。
- 可以一次生成 2–3 句，再挑出带用户原词最多、最短的那一句。
- 评测时加一条“可替换测试”：把收尾句放到另一个用户的对话后面还说得通，就算失败。

## 6. 不确定的地方

- 知乎条目全部来自二手合集或搜索摘要。合集里有些“知乎神回复”可能本来就是书里或电影里的句子（比如 #27 #22 常被安到别人头上），作者署名和原文措辞都没法核对。
- #31 #32 #33 #36 #37 只看到搜索摘要，没打开原页，措辞可能有出入；#37 蔡澜那条尤其要当转述看。
- 网易云的赞数在合集里都没给。只有豆瓣和 V2EX 的赞数是页面上直接看到的，豆瓣小组楼层的赞数和知乎万赞不在一个量级。
- 小红书基本没覆盖到，只有一个间接来源；如果客户特别看重小红书的口吻，需要人工登录补一轮。
